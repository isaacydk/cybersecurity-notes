# SOC
## Common SOC Tools 
- **CrowdStrike Falcon** detects suspicious process on endpoint
- **Splunk SIEM** correlates with network logs from **Palo Alto firewall**
- **ThreatConnect** provides threat intelligence about the attack
- **Phantom SOAR** automatically isolates the affected endpoint
- **SentinelOne** performs forensic analysis and remediation

## Core SOC  Tools

### SIEM (Security Information and Event Management)

Popular SIEMs:

- **Splunk**: Most widely used, powerful search capabilities
- **IBM QRadar**: Enterprise-focused, strong correlation engine
- **ArcSight**: HP Enterprise product, good for large organizations
- **LogRhythm**: User-friendly interface, good for mid-size companies
- **Microsoft Sentinel**: Cloud-native, integrates with Microsoft ecosystem

### EDR (Endpoint Detection and Response)

Leading EDR Platforms:

- **CrowdStrike Falcon**: Cloud-native, excellent threat hunting capabilities
- **SentinelOne**: Strong AI/ML detection, good for autonomous response
- **Carbon Black**: VMware product, good integration with VMware ecosystem
- **Microsoft Defender for Endpoint**: Integrates with Microsoft security stack
- **Cylance**: AI-powered prevention, now part of BlackBerry

### Network Monitoring and Analysis

Key Network Tools:

- **Wireshark**: Free packet analyzer for deep packet inspection
- **tcpdump**: Command-line packet capture tool
- **Zeek (Bro)**: Network security monitoring platform
- **Suricata**: Open-source IDS/IPS with multi-threading
- **Snort**: Popular open-source intrusion detection system
- **Network Taps**: Gigamon, Ixia, Endace for passive monitoring

### Firewall and Network Security

Popular Firewall Vendors:

- **Palo Alto Networks**: Next-gen firewall leader, strong application control
- **Fortinet FortiGate**: Good performance-to-price ratio, unified threat management
- **Cisco ASA**: Enterprise standard, integrates with Cisco ecosystem
- **Check Point**: Strong security features, good for large enterprises
- **pfSense**: Open-source, good for small to medium businesses

### Threat Intelligence Platforms

Key Threat Intelligence Platforms:

- **ThreatConnect**: Comprehensive threat intelligence platform
- **MISP**: Open-source threat sharing platform
- **Anomali**: Good for threat hunting and investigation
- **Recorded Future**: Real-time threat intelligence
- **IBM X-Force**: Enterprise threat intelligence service

### Automation and Orchestration Tools

Leading SOAR (Security Orchestration, Automation, and Response)Solutions:

- **Phantom (Splunk)**: Most popular, strong playbook automation
- **IBM Resilient**:Enterprise-focused, good integration capabilities
- **Demisto (Palo Alto)**: Now Cortex XSOAR, strong threat intelligence integration
- **Swimlane**: Good for mid-size organizations, user-friendly
- **Siemplify**: Strong case management and workflow capabilities
